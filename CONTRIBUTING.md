# Contributing to Portfolio

First off, thanks for taking the time to contribute! ❤️

This project is a modern, customizable portfolio template built with Next.js 16, React 19, and Tailwind CSS. Whether you're fixing a bug, adding a feature, or improving documentation, all contributions are welcome.

This project adheres to a standard of professional, inclusive, and constructive collaboration. Harassment or toxic behavior will not be tolerated.

## Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, pnpm, or bun

### Setup

```bash
# Fork the repository on GitHub, then clone your fork
git clone https://github.com/YOUR_USERNAME/portfolio.git
cd portfolio

# Install dependencies
npm install

# Create a branch for your changes
git checkout -b feature/your-feature-name

# Start development server
npm run dev
